# Optima-style шаблоны ответов (Reply Macros · RU / KY)

> Короткие, доброжелательные и структурированные шаблоны с переменными `{variable}` для первичных ответов бота и быстрой вставки менеджерами CRM. Парсится автоматически для наполнения таблицы `reply_templates`.

## Macro: greeting_hot_lead
- category: greeting
- title: Приветствие и уточнение запроса (горячий лид)
- variables: name, subject, manager_name

```ru
Здравствуйте, {name}! Спасибо за обращение в Monday Academy. Подскажите, пожалуйста, для кого подбираем подготовку по направлению «{subject}» и какой формат удобнее — онлайн или офлайн? Если удобно, поделитесь номером телефона кнопкой ниже — {manager_name} быстро подберёт подходящую группу и время.
```

```ky
Саламатсызбы, {name}! Monday Academy мектебине кайрылганыңызга рахмат. «{subject}» багыты боюнча даярдык кимге керек жана кайсы формат ыңгайлуу — онлайнбы же офлайнбы? Ыңгайлуу болсо, төмөнкү баскыч аркылуу телефон номериңизди жөнөтүп коюңуз — {manager_name} сизге ылайыктуу топту жана убакытты тез тандап берет.
```

## Macro: course_price_overview
- category: pricing
- title: Ответ на вопрос о стоимости и форматах
- variables: name, subject, price_placeholder, schedule

```ru
Здравствуйте, {name}! По направлению «{subject}» у нас есть занятия в мини-группах и индивидуально (онлайн и офлайн), расписание: {schedule}. {price_placeholder}. Чтобы назвать точную стоимость под вашу цель и расписание, поделитесь, пожалуйста, контактом — менеджер сразу свяжется и подберёт оптимальный вариант.
```

```ky
Саламатсызбы, {name}! «{subject}» багыты боюнча бизде чакан топтордо жана жеке сабактар бар (онлайн жана офлайн), жадыбал: {schedule}. {price_placeholder}. Максатыңызга жана убактыңызга жараша так баасын айтып бериш үчүн номериңизди калтырыңыз — менеджерибиз дароо байланышып, эң ыңгайлуу вариантты сунуштайт.
```

## Macro: trial_lesson_booking
- category: trial
- title: Приглашение на пробный / диагностический урок
- variables: name, subject, trial_time, branch

```ru
Отлично, {name}! С радостью запишем на пробный диагностический урок по «{subject}» ({branch}). Ближайшее ориентировочное окно: {trial_time}. Нажмите кнопку «Поделиться контактом» или напишите номер телефона, чтобы менеджер закрепил место и прислал детали.
```

```ky
Эң сонун, {name}! «{subject}» боюнча сынамык диагностикалык сабакка ({branch}) кубануу менен жазабыз. Жакынкы убакыт: {trial_time}. Орунду бекитип, толук маалымат жөнөтүү үчүн «Контакт менен бөлүшүү» баскычын басыңыз же номериңизди жазып коюңуз.
```

## Macro: reschedule_lesson
- category: reschedule
- title: Подтверждение запроса на перенос занятия
- variables: name, trial_time, manager_name

```ru
Поняли вас, {name}! Передали запрос на перенос времени ({trial_time}) менеджеру ({manager_name}). В ближайшее время согласуем новое удобное окно и подтвердим здесь или по телефону.
```

```ky
Түшүндүк, {name}! Убакытты ({trial_time}) жылдыруу боюнча өтүнүчүңүздү менеджерге ({manager_name}) өткөрүп бердик. Жакында ыңгайлуу жаңы убакытты макулдашып, тактап беребиз.
```

## Macro: follow_up_parent_objection
- category: objection
- title: Мягкая отработка возражения («дорого» / «подумаю»)
- variables: name, subject

```ru
{name}, понимаю, выбор подготовки по «{subject}» — важное решение. Предлагаем начать без обязательств с диагностического/пробного урока: ученик посмотрит платформу и преподавателя, а менеджер подберёт подходящий по бюджету и графику формат. Подсказать ближайшие слоты?
```

```ky
{name}, түшүнөм, «{subject}» боюнча даярдыкты тандоо — маанилүү чечим. Эч кандай милдеттенмесиз диагностикалык/сынамык сабактан баштап көрүүнү сунуштайбыз: окуучу платформаны жана мугалимди көрөт, ал эми менеджер бюджетиңизге жана убактыңызга ылайык форматты тандап берет. Жакынкы убакыттарды айтайынбы?
```

- title: Вежливый запрос номера телефона для завершения заявки

```ru

```

```ky
{name}, «{subject}» боюнча өтүнүчүңүздү жоготпоо жана менеджер сизге жадыбал менен шарттарды дароо жөнөтө алышы үчүн төмөнкү «Контакт менен бөлүшүү» баскычын басыңыз же телефон номериңизди жазып коюңуз.
```
